# 🌐 API and Mock Data Handling

---

## 🧪 Mock API Support

Mock API responses are stored in the `assets/` folder.

When adding a new API:

1. Create a new `.json` file in the `assets` folder
2. Make sure the file name is the **endpoint of the API**

Example:  
For endpoint `translations`, the file should be named `translations.json`

---

## 🔁 Usage

These mock responses are used to simulate API calls during development.
